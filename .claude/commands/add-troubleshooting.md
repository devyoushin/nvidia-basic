`$ARGUMENTS`를 파싱하여 기존 문서의 트러블슈팅 섹션에 새 항목을 추가합니다.
- 첫 번째 인자: 대상 파일 경로
- 나머지 인자: 증상 설명 (자유 텍스트)

## 작성 규칙

1. 대상 파일을 먼저 읽어 기존 트러블슈팅 섹션 파악
2. 기존 항목과 중복되지 않는지 확인
3. `rules/doc-writing.md` 섹션 5번 형식으로 작성:
   - **증상**: 오류 메시지, `dmesg` 출력 예시 포함
   - **원인**: 근본 원인 (Xid 에러면 에러 코드 + 의미 설명)
   - **해결 방법**: 진단 → 해결 명령어 순서
   - **예방책**: 재발 방지 방법

## nvidia-smi 트러블슈팅 특이사항

- Xid 에러는 반드시 코드 번호와 AWS 권고 조치를 함께 기재
- `dmesg -T | grep NVRM` 출력 예시를 항상 포함
- GPU 리셋(`nvidia-smi -r`) 사용 시 선행 조건(프로세스 없음) 명시
