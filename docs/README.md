# nvidia-basic 문서

이 디렉토리는 주제별 번호 체계로 문서를 정리합니다. 앞 번호는 학습과 운영 흐름을 나타내며, 90번대는 저장소 관리용 문서입니다.

## 문서 구조

- [01-driver](./01-driver/): NVIDIA 드라이버 - 드라이버 설치와 버전 관리 문서를 모읍니다.
- [02-nvidia-smi](./02-nvidia-smi/): nvidia-smi - GPU 조회, 모니터링, reset 명령 문서를 모읍니다.
- [03-cuda](./03-cuda/): CUDA와 컨테이너 - CUDA 호환성과 NVIDIA Container Toolkit 문서를 모읍니다.
- [04-dcgm](./04-dcgm/): DCGM - DCGM 설정과 필드 그룹 문서를 모읍니다.
- [05-monitoring](./05-monitoring/): GPU 모니터링 - CloudWatch, Prometheus, exporter 연동 문서를 모읍니다.
- [06-troubleshooting](./06-troubleshooting/): 문제 해결 - Xid 오류, 드라이버 장애, 호스트 교체 대응 문서를 모읍니다.
- [90-standards](./90-standards/): 문서 작성 표준 - 저장소 문서 작성 규칙과 운영 기준을 관리합니다.
- [91-templates](./91-templates/): 문서 템플릿 - 반복해서 사용하는 문서 템플릿을 관리합니다.
- [99-agents](./99-agents/): AI 에이전트 가이드 - GPU 운영과 문서화에 활용할 에이전트 역할 정의를 관리합니다.
