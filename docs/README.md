# NVIDIA Docs

NVIDIA GPU 운영 문서는 주제별로 나눠 관리합니다.

| 폴더 | 내용 |
|------|------|
| `driver/` | NVIDIA 드라이버 설치, 버전 관리, Fabric Manager |
| `smi/` | `nvidia-smi` 기본 사용, query, monitoring, GPU reset |
| `dcgm/` | DCGM 설치, field group, `dcgmi` 운영 |
| `monitoring/` | CloudWatch GPU metric, DCGM Exporter, Prometheus |
| `cuda/` | CUDA/driver 호환성, NVIDIA Container Toolkit |
| `troubleshooting/` | Xid, driver crash, AWS host replacement |
| `agents/` | AI 전문 에이전트 프롬프트 |
| `rules/` | 문서 작성과 NVIDIA 운영 규칙 |
| `templates/` | 재사용 문서 템플릿 |

운영 스크립트는 `../ops/README.md`를 참고합니다.
